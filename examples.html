1. เทคนิค Prompt Engineering สั่ง AI เจนหน้าเว็บ

การเขียนคำสั่ง (Prompt) ที่ดี เพื่อให้ได้โค้ด HTML/CSS ตรงตามต้องการ

การสั่งงาน AI ให้เขียนโค้ดหน้าเว็บ ควรระบุ **โครงสร้าง (Role)**, **ธีมสี (Style)**, **ส่วนประกอบ (Components)** และ **ความสามารถที่ต้องการ (Features)** ให้ชัดเจน

ตัวอย่าง Prompt สั่งงาน AI:

"ช่วยเขียนโค้ด HTML + Tailwind CSS สำหรับหน้าเว็บสื่อการสอนโทนสีน้ำเงินดำ มี Navbar ด้านบน, การ์ดแสดงข้อมูล 3 ใบที่เปลี่ยนสีได้เมื่อเอาเมาส์จ่อ และฟอนต์ภาษาไทย Prompt อ่านง่าย สภาพแวดล้อมเป็นไฟล์เดียวจบ"

ผลลัพธ์ที่ได้จาก AI:

  • ได้ไฟล์ HTML ที่ดึง CDN ของ Tailwind CSS และ Google Font Prompt มาใช้ทันที
  • จัดเลย์เอาต์ Responsive รองรับการแสดงผลทั้งบนมือถือและคอมพิวเตอร์
  • สร้าง CSS Animation สำหรับเปลี่ยนสีการ์ดและยกตัวขึ้นอัตโนมัติ
✨ เลื่อนเมาส์จ่อเพื่อดูไฮไลต์สีเขียว

2. ตัวอย่างการเขียนโค้ดเชื่อมต่อ AI API (JavaScript)

การดึงคำตอบจาก AI มาแสดงผลบนหน้าเว็บไซต์ด้วย `fetch()` API

นักพัฒนาสามารถส่งคำถามของผู้ใช้ผ่านฟังก์ชั่น JavaScript ไปยังเซิร์ฟเวอร์ของ AI และนำข้อความตอบกลับมาแสดงบนหน้าเว็บได้ทันที ดังตัวอย่างโค้ดด้านล่างนี้: 

async function getAIResponse(userQuestion) {
    // 1. ส่งคำขอไปยัง OpenAI API Endpoint
    const response = await fetch('https://api.openai.com/v1/chat/completions', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Authorization': 'Bearer YOUR_API_KEY_HERE'
        },
        body: JSON.stringify({
            model: 'gpt-4o-mini',
            messages: [{ role: 'user', content: userQuestion }]
        })
    });

    // 2. แปลงผลลัพธ์เป็น JSON และนำข้อความไปแสดงบนเว็บ
    const data = await response.json();
    const aiMessage = data.choices[0].message.content;
    document.getElementById('chat-output').innerText = aiMessage;
}
✨ เลื่อนเมาส์จ่อเพื่อดูไฮไลต์สีเขียว
